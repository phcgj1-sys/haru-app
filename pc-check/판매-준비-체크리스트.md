# 유료 판매 전 체크리스트

프로그램 자체의 품질 검증은 CI(실제 Windows)에서 자동으로 이뤄집니다. 아래는 **판매자가 직접 해야 하는 일**입니다.

## 1. 신뢰 (가장 중요)
- [ ] **코드 서명 인증서** 구매 후 `PC원클릭진단.exe` 와 `PCCheck.ps1` 에 서명
  - 서명이 없으면 Windows SmartScreen 이 "알 수 없는 게시자" 경고를 띄우고, 일부 백신이 ps2exe 로 만든 exe 를 오탐할 수 있음
  - OV 인증서(연 20~40만 원대)도 가능하지만 SmartScreen 평판은 EV 인증서가 가장 빠름
  - 서명 명령 예: `signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /a PC원클릭진단.exe`
- [ ] 배포 파일의 SHA-256 을 판매 페이지에 공개 (`Get-FileHash PCCheck.zip`)
- [ ] 바이러스토탈(virustotal.com)에 올려 오탐 여부 확인, 오탐 시 각 백신사에 오탐 신고

## 2. 라이선스·법적
- [ ] [THIRD-PARTY.md](THIRD-PARTY.md) 확인: 외부 도구는 번들하지 않고 사용자가 공식 출처에서 받음
- [ ] 수리점처럼 **기술자가 업무로** HWiNFO/OCCT 를 쓰면 해당 상업용 라이선스 필요
- [ ] 판매 페이지·보고서에 "진단은 Windows 기록 기반 추정이며 부품 고장을 보증하지 않음" 고지 (보고서 하단에 이미 포함)
- [ ] 개인정보: 프로그램은 외부 전송이 없음. 원격 상담으로 JSON 을 받는다면 컴퓨터 이름·하드웨어 정보가 포함됨을 고객에게 안내

## 3. 서비스 구성 아이디어
| 상품 | 내용 |
|---|---|
| 무료 | 진단 보고서 (점수·원인 Top 3) |
| 유료 상담 | 고객이 보낸 `.json` 을 `-FromJson` 으로 열어 원격 분석 + 해결 순서 안내 |
| 출장/수리점 | 수리 전후 검사 → "지난 검사 대비" 카드로 수리 효과를 고객에게 증명 |

## 4. 출시 전 실기 테스트 (CI 가 못 하는 것)
- [ ] 실제 그래픽카드가 있는 PC 2~3대(NVIDIA·AMD)에서 GUI 실행, 화면 배율 100%/150% 확인
- [ ] 문제가 있던 PC(블루스크린·갑자기 꺼짐 경험)에서 원인 순위가 실제와 맞는지 확인
- [ ] 관리자 권한 거부 시 동작, 압축을 풀지 않고 실행했을 때 안내 문구 확인
