# 외부 도구 및 라이선스 안내

PC 원클릭 진단 본체(`PCCheck.ps1`)는 Windows 기본 기능만 사용하며, 외부 프로그램을 **포함(재배포)하지 않습니다.**
아래 도구는 사용자가 메뉴에서 선택했을 때만 **공식 출처**에서 받아 실행하거나, 공식 사이트를 열어 줍니다.

| 도구 | 출처 | 받는 방법 | 라이선스/사용 조건 (판매 시 반드시 확인) |
|---|---|---|---|
| memtest_vulkan | github.com/GpuZelenograd/memtest_vulkan | GitHub 최신 릴리스 자동 다운로드, GitHub 가 제공하는 SHA-256 으로 무결성 검증 | 오픈소스 — 저장소의 LICENSE 파일 조건을 따름 |
| BlueScreenView | nirsoft.net | 공식 zip 자동 다운로드 | 프리웨어. 상업적 재배포 제한 → 이 프로그램은 번들하지 않고 사용자 PC 에서 직접 받음 |
| Windows 메모리 진단 | Windows 기본 내장 | - | Windows 구성 요소 |
| HWiNFO | hwinfo.com | 공식 사이트만 열기 | 개인 무료. **업무/상업적 사용은 유료(Pro) 라이선스 필요** |
| OCCT | ocbase.com | 공식 사이트만 열기 | 개인 무료. **업무/상업적 사용은 유료 라이선스 필요** |

> 수리점·출장 점검 등 **유료 서비스 과정에서 기술자가 직접** HWiNFO/OCCT 를 사용한다면 해당 업체의 상업용 라이선스를 구매해야 합니다.
