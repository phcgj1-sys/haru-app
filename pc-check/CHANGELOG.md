# 변경 이력

## 2.8.0
유명 진단 도구(Prime95·OCCT·MemTest86·CrystalDiskInfo·HWiNFO 등)와 비교한 개선 — 비교-개선목록.md

- 142회: [기능] CPU 부하에 연산 검증 추가 (Prime95·OCCT 방식) — 같은 계산을 반복해 결과가 달라지면 CPU 연산 오류로 기록(CPUERR), 블랙박스가 CPU 불안정으로 판정, 화면에 오류 수 표시
- 143회: [기능] 디스크 SMART 확장 (CrystalDiskInfo 방식) — 쓰기 오류(복구 불가)·기록상 최고 온도 수집과 보고서 표시, 쓰기 오류는 디스크 원인, 약 4년(3.5만 시간) 넘게 쓴 HDD·과거 고온(HDD 60°C·SSD 80°C) 안내
- 144회: [기능] 노트북 배터리 마모율 (BatteryInfoView 방식) — 설계 용량·완충 용량·충전 횟수 수집(읽기만), 40% 이상 마모면 경고·교체 권장(갑자기 꺼짐이 있으면 전원 원인 근거), 20% 이상 안내
- 145회: [기능] 온도 모니터에 HWiNFO 처럼 최고·평균·최저값과 그래픽카드 팬 회전수(가장 뜨거운 카드, Windows 센서) — 창을 키워 줄바꿈으로 글자가 잘리지 않게
- 146회: [기능] 온도 모니터 기록 저장 (HWiNFO 로깅 방식) — '기록 저장 시작'을 누르고 고른 CSV 파일에 매 측정값을 한 줄씩(지역 설정과 무관한 소수점), 다시 누르거나 창을 닫으면 멈춤
- 147회: [기능] Windows 안 RAM 검사 패턴을 4종 → 7종으로 (MemTest86 방식: 반전 교차·walking 1·walking 0 추가 — 비트 고착·이웃 비트 간섭 검출)
- 148회: [기능] 보고서 위쪽 '부품 요약' 표 (AIDA64 방식) — CPU(코어/스레드)·메인보드·BIOS·RAM(구성·종류·속도)·그래픽카드(VRAM)·저장장치·전원(권장 파워 또는 노트북 배터리 마모)·Windows
- 149회: [기능] 블루스크린 매개변수 해석 (WhoCrashed 방식) — 이벤트 문장과 미니덤프 헤더에서 매개변수 4개를 읽어 0x124(CPU 내부 오류·PCIe 장치·NMI)·0x101(멈춘 코어)·0x9F·0x133·0x1A·0x1E/0x3B 를 쉬운 말로, 보고서 블루스크린 표 '매개변수 해석' 칸
- 150회: [기능] 시스템 디스크 읽기 속도 (CrystalDiskMark 대신, 읽기 전용) — Windows 폴더의 기존 큰 파일을 최대 2초·128MB 읽어 MB/s, 30 MB/s 미만이면 경고(캐시로 높게 나올 수는 있어도 낮게는 안 나오므로 느림만 판정), 부품 요약에 표시
- 151회: [기능] 디스크별 종합 상태 '좋음·주의·나쁨' (CrystalDiskInfo 방식 — 상태·마모·읽기/쓰기 오류·온도를 한 단어로), 보고서 저장장치 표 첫 칸과 부품 요약에 표시. 비교 목록에 새 차이 3개 추가
- 152회: [기능] 정밀 테스트 통과 확인서 (OCCT 결과 인증 방식) — 블랙박스 전 단계 통과 기록이 있으면 보고서 위쪽에 날짜·시간·단계별 최고값·CPU/RAM/VRAM 오류 0·매장 이름·서명란 (수리 후 고객 안내용, 인쇄 가능)
- 153회: [기능] 덤프 파일 표에도 블루스크린 매개변수 해석(미니덤프 헤더에서 읽은 값)과 원인 드라이버(.sys) 확인 안내(BlueScreenView) — 정확한 드라이버 이름 자동 추출은 검증할 수 없어 오판 방지를 위해 제외
- 154회: [기능] CPU 실제 클럭(GHz) 표시 (HWiNFO 의 Core Clock 처럼 기준 클럭 × 성능 %) — 온도 모니터와 모니터 기록 CSV(CpuMHz 열)에. 비교 목록에 새 차이 2개 추가
- 155회: [기능] 노트북 전원 상태 (BatteryInfoView 방식) — 온도 모니터에 배터리 잔량·어댑터 연결/배터리 사용 표시, 모니터 기록 CSV 에 BatteryPct·OnAC 열 (배터리 사용 중 고부하에서 꺼지는지 확인용)

## 2.7.0
부품별 진단 정리와 실시간 온도 모니터

- 111회: [기능] 실시간 온도 모니터(설치 없음) — CPU·메인보드 온도(관리자 ACPI → 일반 권한 열 영역 카운터), 그래픽카드 온도·사용률·전력·클럭·VRAM 사용량, RAM 사용률, 최고값·고온 경고. '온도·전압 모니터링' 버튼이 사이트를 여는 대신 이 창을 열고, 전압·팬은 창 안의 HWiNFO 버튼. 블랙박스 기록의 CPU·메인보드 온도도 일반 권한에서 읽힘
- 112회: [CI 수정] 온도 모니터 창의 영어 버튼 'Open HWiNFO (voltages/fans)' 가 잘려 GUI 배치 검사 실패 — 버튼 폭 재배분, 폭·겹침 검사 추가
- 113회: [수정] 노트북 그래픽카드(RTX 4090 Laptop GPU 등)를 데스크톱 표로 계산해 750W 이상 파워를 권하던 오판 — 노트북은 권장 파워를 내지 않음
- 114회: [수정] 관리자 권한 없이 검사하면 보고서 온도(과열 판정)가 비던 문제 — ACPI 가 거부되면 일반 권한 열 영역 카운터로

- 116회: [수정] 고장 난 USB 메모리·카드 리더를 PC 내부 디스크 문제로 보고 '디스크' 원인 점수·감점을 주던 오판 — 외장 장치는 백업 안내만
- 117회: [수정] 온도 모니터가 고정값만 내는 보드 센서(예: 27.8 °C)를 CPU 온도처럼 보여 주던 문제 — CPU 를 많이 써도 20초간 전혀 변하지 않으면 '실제 CPU 온도가 아닐 수 있음' 표시
- 118회: [수정] 하드디스크(HDD)에도 'SSD 온도 높음 · NVMe 방열판 확인'을 안내하고 기준(70°C)도 HDD 에는 너무 높던 문제 — HDD 는 55°C 부터 HDD 안내
- 119회: [수정] 디스크 연결 방식·종류가 숫자(BusType 7=USB·9=iSCSI, MediaType 3=HDD)로 오는 환경에서 USB·노하드·HDD 판정이 조용히 빠지던 문제 — 수집할 때 이름으로 통일
- 120회: [수정] 내장+외장 그래픽처럼 GPU 센서가 여럿이면 첫 번째(덜 뜨거운 내장 그래픽일 수 있음) 온도만 읽어 부하 테스트 과열 보호·온도 모니터가 늦던 문제 — 가장 뜨거운 값 사용
- 121회: [수정] NVIDIA 카드가 여러 장이면 nvidia-smi 의 첫 줄(첫 카드)만 읽어 둘째 카드 과열을 놓치던 문제 — 가장 뜨거운 카드 기준
- 122회: [수정] 그래픽카드가 2장 이상이면 가장 큰 한 장의 전력만으로 권장 파워를 계산해 작게 권하던 문제 — 카드별 전력(제한값·모델 대표값) 합계

- 124회: [수정] 블랙박스 기록 중 USB 를 뽑으면 생기는 disk 157(갑자기 제거됨) 경고를 디스크 오류로 기록해 판정이 디스크 탓으로 가던 문제
