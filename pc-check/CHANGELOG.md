## 2.2.0

- 1회: [버그] 지역 설정 따라 시간 구분자·소수점이 바뀌어 기록을 다시 못 읽던 문제 수정 (핀란드어·독일어 Windows 등)
- 2회: [버그] 단계별 테스트에서 memtest_vulkan 이 찾은 VRAM 오류가 기록되지 않고, 도구가 시작 실패해도 GPU 단계가 '통과'로 나오던 문제 수정 (출력 파일 해석)
- 3회: [버그] GUI 검사(백그라운드 수집)에 GPU 센서 코드·단계 계획이 전달되지 않아 AMD·Intel 온도를 못 읽고 블랙박스 단계 이름이 빠지던 문제 수정
- 4회: [버그] 수리 후 단계별 테스트를 모두 통과해도 이전 블랙박스 실패가 30일간 계속 감점되던 문제 → 이후 통과 기록이 있으면 '해결됨' 참고로 표시
- 5회: [버그] 자동 테스트 중 GPU 도구 다운로드·실행 실패가 조용히 묻혀 GPU 단계가 통과로 보이던 문제 → 시작 전에 미리 준비·실패 시 즉시 안내·기록
- 6회: [버그] RAM 검사를 멈춰도 확보한 메모리를 바로 돌려주지 않아 이어지는 GPU·전체 부하 단계가 메모리 부족 상태로 돌던 문제 수정
- 7회: [버그] GPU 도구가 돌지 않았는데 GPU 단계에서 꺼지면 '그래픽카드 의심'으로 잘못 판정하던 문제 → 실제 부하 기준(대기·CPU 단독)으로 판정
- 8회: [버그] 칩셋·SATA·HDMI 오디오 드라이버 설치를 그래픽 드라이버로 잘못 잡아 '드라이버 설치 직후 문제' 거짓 판정 → 디스플레이 INF·장치명 기준 판별
- 9회: [버그] '이후 테스트 통과' 안내·로그 시간이 지역 설정 구분자를 따라 영어 보고서에 한글이 남던 문제 수정
- 10회: [버그] 블랙박스 '직접 설정' 기록의 단계 이름이 내부 키(manual)로 표시되던 문제 수정
- 11회: [기능] 보고서에 블랙박스 기록 그래프(GPU 온도·전력·CPU 사용률, 단계 구간, 끊긴 지점) / [버그] 정수 [math]::Min/Max 함정으로 전원 버튼 할인·차트 막대가 정수로 잘리던 문제 수정

## 2.1.0
- 노하드 정밀 테스트: 단계별 자동 부하(대기→CPU→RAM→GPU→전체→전력 출렁임), Windows 안 RAM 검사, CPU 클럭·메인보드 온도·NVIDIA 감속 원인 기록, 꺼진 단계 기반 판정
- 블랙박스 기록(노하드용): 부하 테스트 중 상태를 USB 에 실시간 기록 → 꺼진 뒤 원인 자동 분석, CPU 부하 내장
- '검사 시작' 직후 프로그램이 꺼지던 버그 수정, 화면 오류 안전망, CI 에서 실제 검사 흐름 끝까지 실행
- 영어 보고서·화면·콘솔 지원 (`-Lang en`, 기본은 Windows 언어 자동 감지)
- GitHub API 한도 초과 시에도 VRAM 검사 도구를 받을 수 있도록 검증된 고정 버전(SHA-256) 대체 경로
- 검사 중 창이 멈추지 않도록 수집을 백그라운드에서 실행
- AMD·Intel 포함 제조사 무관 그래픽카드 온도/팬 읽기 (Windows 제공 센서)
- 화면 배치를 창 크기·배율 기반으로 재작성 (1366×768 노트북 + 125% 배율 등 작은 화면 대응, DPI 인식)
- 지난 검사 대비: 이후 새로 생긴 문제를 보고서 맨 위에 표시
- 블루스크린 덤프 저장 꺼짐·페이지 파일 없음 감지 (기록 누락으로 인한 오판 방지)
- 절전 진입/복귀 중 꺼짐, 전원 버튼 강제 종료 구분 (Kernel-Power 41 필드를 이름으로 읽음)
- 가상 머신 감지, 보고서 "지금 할 일" 한 줄 안내, 원격 상담용 JSON 안내
- PowerShell 5.1 전용 버그 수정 (단일 항목 목록, JSON 배열 읽기)
