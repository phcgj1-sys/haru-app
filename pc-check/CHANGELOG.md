# 변경 이력

## 2.1.0
- 영어 보고서·화면·콘솔 지원 (`-Lang en`, 기본은 Windows 언어 자동 감지)
- GitHub API 한도 초과 시에도 VRAM 검사 도구를 받을 수 있도록 검증된 고정 버전(SHA-256) 대체 경로
- 검사 중 창이 멈추지 않도록 수집을 백그라운드에서 실행
- AMD·Intel 포함 제조사 무관 그래픽카드 온도/팬 읽기 (Windows 제공 센서)
- 화면 배치를 창 크기·배율 기반으로 재작성 (1366×768 노트북 + 125% 배율 등 작은 화면 대응, DPI 인식)
- 지난 검사 대비: 이후 새로 생긴 문제를 보고서 맨 위에 표시
- 블루스크린 덤프 저장 꺼짐·페이지 파일 없음 감지 (기록 누락으로 인한 오판 방지)
- 절전 진입/복귀 중 꺼짐, 전원 버튼 강제 종료 구분 (Kernel-Power 41 필드를 이름으로 읽음)
- 가상 머신 감지, 보고서 "지금 할 일" 한 줄 안내, 원격 상담용 JSON 안내
- PowerShell 5.1 전용 버그 수정 (단일 항목 목록, JSON 배열 읽기)
