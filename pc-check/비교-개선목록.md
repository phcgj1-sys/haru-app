# 유명 진단 도구와 비교한 개선 목록

PC 원클릭 진단을 널리 쓰는 무료·상용 도구와 비교해, 이 프로그램에 없거나 약한 점을 정리했습니다.
각 항목은 **외부 전송·시스템 설정 변경·파일 삭제 없이** 할 수 있는 것만 골랐습니다. 반복 개선 회차에서 위에서부터 하나씩 구현하고, 끝나면 `[x]` 로 표시합니다.

| 비교 도구 | 그 도구의 강점 | 이 프로그램의 현재 | 개선 방향 |
|---|---|---|---|
| Prime95 · OCCT CPU | 계산 결과를 검증해 **CPU 연산 오류**를 잡음 | CPU 를 100% 돌리기만 함 (꺼짐만 감지) | 부하 중 결과 검증 → 연산 오류 기록·판정 |
| MemTest86 | 다양한 패턴 (walking 1/0, moving inversions) | 주소·반전·교차·난수 4종 | 패턴 추가 |
| CrystalDiskInfo | SMART: 사용 시간·최고 온도·쓰기 오류·전원 횟수 | 상태·수명·온도·읽기 오류 | 사용 시간·최고 온도·쓰기 오류 수집과 판정 |
| HWiNFO | 팬 회전수·최소/평균/최고·CSV 기록 | 온도 모니터는 현재값·최고값만 | 최소·평균, 팬 RPM, 모니터 기록 저장 |
| BatteryInfoView · powercfg | 노트북 배터리 설계 용량 대비 현재 용량(마모) | 없음 | 배터리 마모율 수집과 판정 |
| WhoCrashed | 블루스크린 코드별 쉬운 설명·원인 드라이버 | 코드 설명은 있음, 원인 드라이버는 BlueScreenView | 블루스크린 매개변수 해석(0x124 등) 보강 |
| AIDA64 요약 | 부품 목록 한눈에 | 보고서에 흩어져 있음 | 보고서 상단 '부품 요약' 표 |
| CrystalDiskMark | 디스크 속도 | 없음 | 읽기 전용 순차 읽기 속도 측정 (파일을 만들거나 지우지 않음) |
| FurMark · OCCT GPU | GPU 부하 중 아티팩트·오류 | memtest_vulkan VRAM 오류 | (유지) VRAM 오류 + 드라이버 리셋 감지 |
| Windows 신뢰성 모니터 | 앱 충돌·Windows 오류 기록 | 안정성 지수 | (유지) |

## 구현 순서 (반복 회차용 백로그)
- [x] 1. CPU 부하 중 연산 결과 검증 → 오류 수 기록·블랙박스 판정 (Prime95/OCCT 방식)
- [x] 2. 디스크 SMART 확장: 사용 시간(PowerOnHours)·최고 온도·쓰기 오류 수집, 보고서 표시, 오래 쓴 HDD 안내
- [x] 3. 노트북 배터리 마모율(설계 용량 대비 완충 용량) 수집·판정
- [x] 4. 온도 모니터 최소·평균값과 GPU 팬 회전수
- [x] 5. 온도 모니터 기록을 CSV 로 저장 (사용자가 버튼을 누를 때만, 저장 위치 선택)
- [x] 6. RAM 검사 패턴 추가 (walking ones/zeros)
- [x] 7. 보고서 상단 부품 요약 표 (CPU·메인보드·RAM·GPU·디스크·전원)
- [x] 8. 블루스크린 매개변수 해석 (0x124 WHEA·0x116 TDR·0x50·0x1A 등 쉬운 설명 보강)
- [ ] 9. 디스크 순차 읽기 속도 측정 (읽기 전용, 기존 큰 파일 사용, 느린 디스크 안내)
- [ ] 10. 그 밖에 회차 중 발견한 차이 (이 목록에 추가하고 진행)
