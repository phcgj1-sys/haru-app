# PC 원클릭 진단

**갑자기 꺼짐 · 블루스크린 · 그래픽카드(VRAM) · RAM · 디스크** 문제의 원인을 Windows 기록으로 찾아
가능성 높은 순서대로 알려 주고, 해결 순서까지 안내하는 Windows 10/11용 진단 도구입니다.

- 설치 없음 · 인터넷 없이 동작 · **어떤 정보도 외부로 보내지 않음**
- 결과: 상태 점수(0~100), 의심 원인 Top 3(근거 + 해결 순서), 날짜별 차트, A/S 상담용 요약
- **지난 검사 대비**: 부품 교체·설정 변경 후 다시 검사하면 "그 이후 새로 생긴 문제"를 맨 위에 표시 → 수리 효과 확인
- **블랙박스 기록(노하드용)**: 단계별 자동 정밀 테스트·Windows 안 RAM 검사·VRAM 검사 결과를 USB 에 즉시 기록, 꺼진 단계로 원인 판정, 시간별 그래프·단계별 최고값 표
- **권장 파워 용량**·**다음 정밀 검사 추천**·**과열 보호**(부하 테스트 중 GPU 95°C 지속 시 자동 중지)
- **증상·고객 메모**(`-Note`)와 메신저로 보낼 수 있는 요약 `.txt` 저장, 한국어/영어 보고서
- **요약 복사** 버튼(메신저에 바로 붙여 넣기)·**점수 변화**(최근 5회)·**다음 정밀 검사 추천**·Windows **안정성 지수**·인쇄용 서명란
- **수리점용**: 매장 이름·연락처(`-Shop` 또는 `shop.txt`)를 보고서·창 제목에 표시, **최근 추세**(최근 7일 문제가 잦아지면 안내), 검사 소요 시간
- **오판 방지**: USB·카드 리더 디스크 오류 분리, 그래픽 오류 중복 집계 제거, 멈춘 뒤 전원 버튼으로 끈 경우 구분, 기록이 지워지는 노하드 PC 는 '판단 보류'
- **안전한 저장**: 분석·보고서 생성이 실패해도 원자료(`.json`)를 남겨 `-FromJson` 으로 다시 생성
- **개인정보 가리기**(`-HideName`): 인터넷에 보고서를 올릴 때 PC 이름·사용자 이름을 코드로
- **블랙박스 편의**: 빠른 테스트(약 10분), 종료 예상 시각, 끝나면 판정 바로 표시 · 콘솔 메뉴 '요약 복사' · 무인 실행 결과에 점수·원인

## 사용법
1. ZIP 을 **압축 해제** (압축 상태에서 바로 실행하면 안 됩니다)
2. `원클릭검사.bat` 더블클릭 → 관리자 권한 "예"
3. **검사 시작** 클릭 → 5~40초 후 보고서가 자동으로 열립니다 (`바탕화면\PC진단` 에 저장)

`PC원클릭진단.exe` 가 포함된 배포본이라면 exe 를 더블클릭해도 됩니다 (관리자 권한 요청 내장).

> Windows 가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르세요 (서명되지 않은 스크립트라 표시됩니다).
> 화면 없이 쓰려면 `콘솔모드.bat`.

## 무엇을 분석하나
| 항목 | 근거 | 판단 예 |
|---|---|---|
| 갑자기 꺼짐 | Kernel-Power 41 (코드 0), 6008 | 블루스크린 없이 꺼짐 → 파워·과열·전원 접촉 / 전원 버튼 강제 종료·절전 복귀 중 꺼짐 구분 |
| 블루스크린 | BugCheck 1001 + **미니덤프 헤더 직접 판독** | 30여 개 코드별 원인 가중치 (0x116=그래픽, 0x124=하드웨어, 0x1A=RAM…) |
| 그래픽카드 | TDR 4101, LiveKernelEvent 141/117, nvlddmkm·amdkmdag | NVIDIA Xid 48/63/64/94/95 = **VRAM 오류**, Xid 79 = 버스 이탈 |
| 상관분석 | 이벤트 시간 비교 | 그래픽 오류 직후 15분 내 꺼짐 → 고부하 전력 부족 / 드라이버 설치 직후 문제 시작 |
| 하드웨어 | WHEA 17/18/19/47 | PCIe·CPU·메모리 하드웨어 오류 |
| RAM | 모듈 정보, Windows 메모리 진단 결과 | XMP/EXPO 사용, 서로 다른 RAM 혼용 |
| 디스크 | SMART(상태·온도·마모·읽기오류), disk/Ntfs/stornvme 오류 | |
| 기타 | nvidia-smi 온도, 오버클럭 도구, 드라이버·BIOS 연식, Intel 13/14세대, 가상 머신 감지 | |

## 노하드(디스크 없는 PC)·기록이 안 남는 경우: 블랙박스 기록
재부팅하면 Windows 기록이 사라지는 PC 는 **정밀 검사 → 블랙박스 기록 (노하드용)** 을 쓰세요. USB 를 꽂으면 저장 위치로 자동 선택됩니다.

**단계별 자동 정밀 테스트 (약 32분, 권장)** — 꺼진 단계로 원인을 좁힙니다

시간이 없으면 **빠른 테스트 (약 10분)** 를 체크하세요 — 같은 6단계를 짧게 돌립니다 (1차 점검용, 간헐적 문제는 32분 테스트가 더 잘 잡음).

| 단계 | 시간 | 이 단계에서 꺼지면 |
|---|---|---|
| 대기 (기준값) | 2분 | 전원 연결·멀티탭·메인보드 |
| CPU 단독 부하 | 6분 | CPU 보조전원·메인보드 전원부·CPU 쿨러 |
| RAM 검사 (Windows 안, 재부팅 없음) | 6분 | RAM·XMP (오류가 나오면 꺼지지 않아도 RAM 불량) |
| GPU·VRAM 단독 부하 (memtest_vulkan) | 6분 | 그래픽카드·보조전원 케이블 |
| 전체 부하 (CPU+GPU) | 8분 | **파워 용량 부족** |
| 전력 출렁임 (10초마다 부하 on/off) | 4분 | **파워 품질·노후** (용량이 충분해도) |

매초 USB 에 즉시 기록: 단계, CPU 사용률·클럭(과열·전력 제한 감지), RAM 사용률, 메인보드 온도, GPU 온도·사용률·전력·클럭,
NVIDIA 감속 원인(하드웨어 감속·파워 브레이크 = 전원 공급 문제 신호), RAM 검사 오류 수, 새 오류(WHEA·그래픽 드라이버).
PC 가 꺼지면 USB 를 꽂은 채 다시 켜서 **검사** → 기록을 자동 분석해 보고서에 단계별 결과와 함께 표시합니다.

노하드 PC 로 판단되면 저장 위치를 따로 정하지 않은 경우 **보고서도 USB(`PC진단_reports`)에 저장**하고, 검사 이력도 USB 블랙박스 폴더에 사본을 남겨 재부팅 후에도 **지난 검사 대비·점수 변화**가 이어집니다.

## 원격 상담 (기술자용)
보고서 옆에는 메신저로 바로 보낼 수 있는 짧은 요약 `.txt` 도 함께 저장됩니다. `.json` 파일을 받으면 어느 PC 에서든 같은 보고서를 다시 만들 수 있습니다.
```powershell
powershell -ExecutionPolicy Bypass -File PCCheck.ps1 -FromJson "PC진단_내PC_20261114_120000.json"
```

## 명령줄 옵션
| 옵션 | 설명 |
|---|---|
| `-Mode Gui / Console / Silent` | 화면 / 콘솔+메뉴 / 무인(보고서만 — 결과 개체에 `Html`·`Json`·`Txt` 경로와 `Health`·`Grade`·`TopCause` 포함, 여러 PC 자동 분류용) |
| `-Days 90` | 분석 기간 (1~365일) |
| `-OutDir D:\reports` | 저장 위치 |
| `-FromJson file.json` | 저장된 진단 데이터로 보고서 재생성 |
| `-NoOpen` | 보고서 자동 열기 끔 |
| `-Note "홍길동 / 게임 중 꺼짐"` | 증상·고객 메모를 보고서 상단과 상담용 요약에 표시 (화면에서는 '메모' 칸) |
| `-Shop "OO컴퓨터 · 010-0000-0000"` | 매장(점검자) 이름·연락처를 보고서 상단·하단과 요약에 표시. 매번 쓰기 번거로우면 프로그램 옆 `shop.txt` 첫 줄에 적어 두면 자동 적용 |
| `-HideName` | 보고서·요약·JSON 에서 PC 이름을 `PC-1a2b3c` 같은 코드로 바꿈 (인터넷에 보고서를 올릴 때. 같은 PC 는 늘 같은 코드라 지난 검사 대비는 유지) |
| `-Lang en` | 영어 보고서·화면 (기본 `auto`: Windows 언어가 한국어면 한국어, 아니면 영어) |

로그: `%LOCALAPPDATA%\PCCheck\logs` · 검사 이력: `%LOCALAPPDATA%\PCCheck\history.json`

## 개발
- 테스트: `pwsh -File tests/Run-Tests.ps1` (PowerShell 5.1 / 7, 원인 시나리오 9종 + 회귀 테스트, 외부 모듈 불필요)
- CI: `.github/workflows/pc-check.yml` — windows-latest 에서
  단위 테스트(5.1·7) → PSScriptAnalyzer(5.1 호환) → 실제 검사(5.1·7) → GUI 레이아웃 자동 검사(배율 100~200%) →
  외부 도구 실제 다운로드·SHA-256 검증 → EXE 빌드(ps2exe) → 배포 ZIP
- EXE 직접 빌드: `powershell -File build/Build-Exe.ps1 -OutDir dist` (Windows PowerShell 5.1)

- 소스 규칙: `PCCheck.ps1` 은 UTF-8 **BOM** + CRLF (5.1 한글 깨짐 방지), `.bat` 은 ASCII + CRLF
