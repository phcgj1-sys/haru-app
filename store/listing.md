# 하루 학습 — Google Play 스토어 등록 정보

## 앱 이름 (30자 이내)
하루 학습

## 간단한 설명 (80자 이내)
하루 15분 매일 공부. 외국어·생활 기초·업무 도구·AI까지 35가지 학습 앱을 한곳에서.

## 자세한 설명 (4,000자 이내)
하루 15분, 매일 조금씩. ‘하루 학습’은 35가지 학습 앱을 한곳에 모은 무료 학습 앱이에요. 회원가입 없이 바로 시작하고, 진도는 내 휴대폰에만 저장돼요.

■ 이런 분께 좋아요
• 출퇴근길 15분으로 외국어 감각을 잃지 않고 싶은 분
• 가계부·세금·문서 작성처럼 생활에 바로 쓰는 기초를 다지고 싶은 분
• 엑셀·구글 시트 사용법, 홈페이지·영상 만들기 같은 업무 기술을 배우고 싶은 분
• AI가 어떻게 작동하는지 기초부터 차근차근, 직접 만들어 보며 이해하고 싶은 분

■ 35가지 학습 앱
• 외국어: 영어(단어·통문장·역할극·생활 장면 듣기), 일본어, 태국어, 영어 듣기 집중
• 생활 기초: 스마트폰·컴퓨터 기초, 돈 관리 기초, 사진·영상 편집 기초, AI로 글쓰기
• 일과 도구: 엑셀, 구글 시트·폼, AI 도우미(Claude) 사용법, 홈페이지 만들기, 유튜브 채널 운영, 깃허브, 리눅스 서버 장애 판별, 윈도우 PC 장애 판별, 네트워크 기초, 쉘 스크립트와 서버 자동화
• AI 기초: 개발 환경과 수학, 머신러닝·딥러닝, 컴퓨터 비전, 자연어 처리, 생성형 AI와 음성, 강화학습, 트랜스포머와 LLM 직접 만들기
• AI 엔지니어링: LLM 앱 만들기, 멀티모달, 도구와 프로토콜(MCP), 리버스 엔지니어링, 에이전트, 자율 시스템, 다중 에이전트, 인프라와 운영, 윤리·안전·정렬, 캡스톤 프로젝트

■ 이렇게 배워요
• 핵심 3줄 요약 → 본문 → 따라 하기 → 퀴즈 3문제 → 실습 과제
• 답을 고르면 바로 해설이 나와요
• 틀린 문제는 ‘오늘의 복습’에 먼저 나와서 자연스럽게 다시 풀게 돼요
• 수업 1025개를 한 번에 검색하고, 다른 앱의 관련 수업으로 이어서 볼 수 있어요
• 연속 학습일과 최근 기록으로 습관을 만들어요
• 외국어는 발음 듣기(기기 음성), 간격 반복 복습, 역할극으로 연습해요

■ 편하게
• 회원가입·로그인 없음, 광고 없음
• 한 번 연 수업은 인터넷 없이도 열려요
• 다크 모드 지원, 큰 글씨로 읽기 쉬운 화면
• 모든 앱 진도를 한 번에 백업하고 새 휴대폰으로 옮길 수 있어요

■ 개인정보
개인정보를 수집하지 않아요. 학습 기록은 기기 안에만 저장되고 서버로 보내지 않아요. 분석 도구·광고·추적 쿠키를 쓰지 않아요.

■ 알려 드려요
• 하루 학습은 독립적으로 만든 비공식 학습 앱이에요. Anthropic(Claude), Google(YouTube·Google 시트·Google 폼), Microsoft(Excel), GitHub 등 언급된 회사와 제휴·후원·승인 관계가 없으며, 각 상표는 해당 소유자의 것이에요.
• AI 엔지니어링 수업은 MIT 라이선스로 공개된 AI Engineering from Scratch(© 2026 Rohit Ghumare)를 한국어로 옮기고 다시 정리했어요.
• 돈·세금 수업은 교육 자료이며 개별 세무·투자 자문이 아니에요.
• AI와 대화하는 연습 기능은 웹 버전을 claude.ai에서 열었을 때만 동작해요. 앱에서는 프롬프트를 복사해 원하는 AI 서비스에 붙여 넣어 쓸 수 있어요.
