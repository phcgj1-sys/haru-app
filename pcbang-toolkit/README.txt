==========================================================
  PC방 윈도우11 최적화 도구 v1.1 - 사용법
==========================================================

[가장 쉬운 사용법 - 3단계]
  1. 복원 프로그램(디스크 보호)을 "해제"하고 재부팅
  2. Start-GUI.bat 더블클릭 -> "② 권장 선택" -> "▶ 선택 항목 적용"
  3. 재부팅 -> 문제 없으면 복원 프로그램 다시 켜기 -> 이미지 떠서 다른 PC에 배포

  ※ 손님이 실제로 쓰는 계정으로 로그인해서 실행하세요.
     (마우스 가속, 알림 같은 설정은 실행한 계정에만 적용됩니다)
  ※ 폴더째로 USB에 넣고 다니면 됩니다. backup / logs 폴더가 자동으로 생깁니다.


[파일 설명]
  Start-GUI.bat          체크박스 화면. 골라서 적용 / 되돌리기 / 상태 확인 / PC 진단
  Apply-Safe.bat         "안전" 항목만 화면 없이 바로 적용
  Apply-Recommended.bat  "권장" 항목(안전 포함) 화면 없이 바로 적용 (여러 대 작업용)
  Undo-All.bat           이 도구로 바꾼 것 전부 원래대로
  PC-Report.bat          PC 진단 (램 XMP, 주사율, 드라이버 날짜, TPM 등) + 항목별 적용 상태
  PCBang-Optimizer.ps1   본체 (맨 위 "사용자 설정"에서 게임 폴더/삭제할 앱 수정 가능)
  install\               윈도우 새로 설치할 때 쓰는 파일
     autounattend.xml    설치 USB 맨 위에 복사 -> MS 계정/개인정보 화면 건너뛰고 로컬 계정 "PC" 생성
     run_setup.bat       설치 직후 실행 -> VC++/DirectX/.NET 설치, 고정 IP, 자동 로그인, 바이오스 점검


[단계(프리셋) 설명]
  ① 안전  부작용이 거의 없는 것만. 아무 PC에나 적용해도 됨
  ② 권장  PC방에 가장 알맞은 구성. 서비스/업데이트/앱 정리 포함   <- 보통 이걸 쓰세요
  ③ 최대  효과는 작거나, 보안/발열 같은 대가가 있는 항목까지 포함
  선택    문제가 있을 때만 쓰는 항목 (프리셋에 포함 안 됨, 직접 체크)

  - 프리셋 버튼은 체크만 해줍니다. 체크를 직접 더하거나 빼고 적용해도 됩니다.
  - 각 항목에 마우스를 올리면 설명이 나옵니다.
  - "상태" 칸: 적용됨 / 일부 / 미적용 / - (확인 불가 항목)


[항목 목록]
  ■ 전원 / 성능
    안전  최고의 성능 전원 관리, 절전·화면 끄기·빠른 시작 끄기, 게임 모드,
          GPU 스케줄링(HAGS), 게임 바 백그라운드 녹화 끄기
    권장  USB/PCIe 절전 끄기, 창 모드 게임 최적화, 투명·애니메이션 끄기,
          자동 유지 관리 끄기, 검색 색인 끄기,
          NTFS 접근 시간 기록 끄기
    최대  CPU 최소 100%·코어 파킹 끄기,
          멀티미디어 스케줄러 게임 우선순위, 타이머 해상도, 메모리 압축 끄기(16GB↑),
          스토어 앱 백그라운드 막기 (게임패스 매장은 비추천)
    선택  메모리 무결성(VBS) 끄기 (프리셋 제외. 발로란트·롤·배틀필드 6·FACEIT 안티치트가 막을 수 있음)

  ■ 입력 / 화면 / 소리
    안전  마우스 가속 끄기, 고정 키 팝업 끄기, Num Lock 켜기, 통화 시 소리 줄이기 끄기
    권장  Alt+Shift 언어 전환 끄기(한/영 키는 정상), 키 반복 속도 최대
    선택  MPO 끄기 (화면 깜빡임/검은 화면 있을 때만)

  ■ 업데이트 / 네트워크
    안전  드라이버 자동 업데이트 막기, 업데이트 공유를 매장 내부(LAN)로만 제한
    권장  자동 업데이트 끄기(수동), 현재 윈도우 버전 고정(25H2 이상만), 랜카드 절전/그린 이더넷 끄기
          (Wake-on-LAN 원격 켜기는 유지)
    최대  스토어 앱 자동 업데이트 끄기 (게임패스 매장은 비추천)

  ■ 백그라운드 / 서비스 / 앱
    안전  오류 보고 창 끄기, Edge/크롬 백그라운드 끄기, Copilot/Recall 끄기,
          Defender 게임 폴더 예외
    권장  진단 데이터 서비스 끄기, 불필요 서비스(지도/팩스/데모/오류보고/위치) 끄기,
          원격 분석 예약 작업 끄기, OneDrive 제거, 기본 앱 삭제(뉴스/날씨/팀즈 등)
    선택  프린터 서비스 끄기 (출력 안 하는 매장만)

  ■ 화면 정리 / 개인정보 / 보안
    안전  알림·광고·추천 끄기, 시작 메뉴/검색 정리, 작업 표시줄 "작업 끝내기",
          잠금 화면 끄기, 개인정보 옵션 끄기, 클립보드 기록 끄기(비번 유출 방지),
          탐색기 최근 파일 숨기기, USB 자동 실행 끄기


[작업 스케줄러 정리 탭]  (v1.1 추가)
  - 두 번째 탭. 영업 중 갑자기 CPU/디스크를 쓰는 예약 작업을 정리합니다.
  - 목록(약 80개): 디스크/유지 관리(조각 모음, WinSAT, 디스크 진단, Chkdsk, 디스크 정리,
    레지스트리 백업, 구성 요소 정리 ...), 진단/원격 분석, 윈도우 업데이트/Defender 예약 검사,
    프로그램 자동 업데이트(Edge, 크롬, OneDrive, NVIDIA, 오피스, 파이어폭스)
  - 버튼
      ① 안전 / ② 권장 / ③ 최대 선택   단계별로 체크
      ■ 사용 안 함   가장 안전. 보통 이걸 쓰세요
      ✕ 삭제(백업)   작업을 지움. 지우기 전에 XML로 backup\tasks 에 저장
      ○시에 매일 실행  실행 조건을 "매일 ○시" 하나로 바꿈 (영업 안 하는 시간으로 옮기기)
      ↺ 원래대로     위 3가지 모두 바꾸기 전 상태로 복구 (삭제한 작업도 다시 만듦)
  - "전체 작업 보기"를 체크하면 PC의 모든 예약 작업이 나오고, 검색창으로 찾을 수 있습니다.
    (게임 런처 업데이트 작업 등 목록에 없는 것도 끄기/삭제/시간 변경 가능)
  - 일부러 넣지 않은 작업: 시간 동기화, Xbox 클라우드 저장(XblGameSave), TPM/BitLocker,
    UpdateOrchestrator/WaaSMedic(윈도우 보호 작업이라 관리자도 못 바꿈)
  - Apply-Recommended.bat / Apply-Safe.bat 은 같은 단계의 작업도 "사용 안 함"으로 바꿉니다.
    Undo-All.bat 은 작업 스케줄러 변경도 되돌립니다.

[노하드 이미지 프로그램에 탭으로 넣기]
  EMBED-GUIDE.txt 를 보세요. 코드 10줄을 붙이면 기존 프로그램 창에 탭 2개로 들어갑니다.

[되돌리기]
  - 적용하기 전 원래 값이 backup\backup.json 에 저장됩니다.
  - GUI: 되돌릴 항목 체크(또는 "적용된 것 선택") -> "↺ 선택 항목 되돌리기"
  - 전부: Undo-All.bat
  - 적용 전에 시스템 복원 지점도 자동으로 만듭니다 (체크박스로 끌 수 있음).
  - 예외: OneDrive 제거, 기본 앱 삭제는 되돌려도 앱이 다시 설치되지 않습니다
          (스토어/공식 사이트에서 재설치).
  - backup 폴더를 지우면 되돌리기를 할 수 없으니 도구 폴더째로 보관하세요.


[이미지 배포 시 주의]
  - 마스터 PC에서 적용 -> 이미지 배포하면 모든 PC에 똑같이 적용됩니다.
  - 랜카드 절전 끄기는 PC마다 랜카드가 다르면 각 PC에서 한 번 더 적용하세요.
  - 고정 IP / 컴퓨터 이름은 PC마다 install\pcbang_setup.ps1 설정을 바꿔서 실행하거나 직접 설정.


[도구로 못 하는 것 - 직접 확인할 체크리스트]
  바이오스
    □ XMP / EXPO 켜기 (안 켜면 램이 기본 속도로 동작 -> 프레임 손해 큼)
    □ Resizable BAR(Re-Size BAR) 켜기, Above 4G Decoding 켜기
    □ TPM(fTPM/PTT), Secure Boot 켜기 (발로란트 등 필수)
    □ CSM 끄기(UEFI 모드)
  그래픽
    □ 최신 드라이버 설치 (문제 있으면 DDU로 지우고 새로 설치)
    □ NVIDIA 제어판: 전원 관리 모드 "최대 성능 선호", 저지연 모드 "켜기"
    □ 모니터 주사율 최대로 (PC 진단에서 "주의" 뜨면 확인), 모니터 케이블은 그래픽카드에 연결
  기타
    □ 램 2개 장착(듀얼 채널) 확인 - PC 진단에 표시됨
    □ 마우스 폴링레이트 1000Hz 이상 (마우스 SW)
    □ 사운드 기본 장치를 헤드셋으로, 마이크 레벨 확인


[일부러 넣지 않은 "최적화" - 효과 없거나 오히려 해로움]
  ✗ 페이징 파일 끄기          램 부족 시 게임 튕김
  ✗ SysMain/Prefetch 끄기     SSD에서는 이득 없고 로딩만 느려질 수 있음
  ✗ IPv6 끄기                일부 서비스/게임 접속 문제
  ✗ Nagle(TCPNoDelay) 끄기    요즘 게임은 대부분 UDP라 효과 없음
  ✗ bcdedit 타이머 설정       (useplatformclock 등) 오히려 지연 증가 사례 많음
  ✗ 전체화면 최적화 끄기       윈도우11에서는 대부분 불필요, 오히려 손해일 수 있음
  ✗ Defender 완전히 끄기      공용 PC 보안 위험, 일부 게임 문제 (예외 폴더만 추가)
  ✗ 서비스 대량 비활성화      Xbox/게임패스, 오디오, 블루투스 고장 원인
  ✗ 레지스트리 클리너, 메모리 정리 프로그램   효과 없거나 역효과


[문제 해결]
  - 실행하자마자 창이 닫힘: PowerShell 실행이 막힌 경우. bat 파일로 실행했는지 확인.
    logs 폴더의 로그를 확인하세요.
  - 특정 게임이 안 됨: GUI에서 "적용된 것 선택" 후 의심 항목만 남겨 되돌리기.
    (먼저 의심할 것: 메모리 무결성 끄기, 스토어 앱 백그라운드 막기, 기본 앱 삭제)
  - 게임패스 게임이 안 됨: 스토어에서 "Gaming Services", "Xbox" 앱 업데이트
  - 관리자 암호를 넣어서 실행했다는 경고: 사용자 설정(마우스/알림 등)이 손님 계정이 아닌
    관리자 계정에 들어갑니다. 손님 계정을 관리자 그룹에 넣고 실행하세요.
  - 다시 업데이트하고 싶음: "자동 업데이트 끄기", "윈도우 버전 고정"만 되돌린 뒤
    업데이트 -> 다시 적용.
