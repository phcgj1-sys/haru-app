한 번에 점검하기

사양 감지 → 모니터 주사율 → CPU·그래픽 측정 → 인터넷 지연 순서로 자동으로 돌아요(약 40초). 끝나면 인기 게임 10개를 이 PC에서 얼마나 잘 돌릴 수 있는지 보여 줘요. 측정 중에는 다른 창을 띄우지 마세요.

더 정확하게: 윈도우 점검 프로그램

브라우저는 보안 때문에 CPU 모델명, 정확한 RAM 용량, 그래픽 메모리, 게이트웨이·외부 핑(ICMP)을 읽을 수 없어요. 아래 프로그램을 실행하면 이것까지 측정하고, 결과 코드를 클립보드에 복사해 줘요. 그 코드를 내 사양 탭에 붙여넣으면 판정에 바로 반영돼요.

pc-check.bat 받기 pc-check.ps1 받기

두 파일을 같은 폴더에 받고 pc-check.bat을 더블클릭하세요. 설치나 관리자 권한은 필요 없고, 이 PC 정보는 어디로도 보내지 않아요(핑 대상에게 보내는 짧은 신호만 나가요). 윈도우가 "PC 보호" 창을 띄우면 '추가 정보 → 실행'을 누르세요.

PC방 인기 게임 판정

예상 프레임(FPS)은 공식 요구 사양과 부품별 성능 점수(PassMark 근사치)로 계산한 추정치예요. 드라이버·발열·백그라운드 프로그램·맵·인원 수에 따라 ±30% 정도 달라질 수 있어요.

사양 직접 고르기

브라우저가 못 읽는 부품은 직접 고르세요. 모르면 윈도우에서 Ctrl+Shift+Esc → 성능 탭을 열면 CPU·메모리·GPU 이름이 보여요. 고른 값은 이 기기에 저장돼요.

윈도우 점검 프로그램 결과 붙여넣기

pc-check.bat 실행이 끝나면 결과 코드(PCBANG1:로 시작)가 클립보드에 복사돼요. 여기에 붙여넣으세요.

CPU 측정

브라우저 안에서 계산 문제를 풀어 단일 코어와 전체 코어 속도를 재요. 같은 사양 좌석끼리 비교할 때 가장 쓸모 있어요(유독 낮은 좌석 = 발열·전원 모드·백그라운드 문제 의심).

그래픽(GPU) 측정

WebGL로 무거운 화면을 반복해서 그려 처리량을 재요. 화면 잠금·절전 모드면 결과가 낮게 나와요.

브라우저 점수는 게임 성능과 1:1로 같지 않아요. 게임 판정은 부품 모델로 계산하고, 이 점수는 같은 부품인데 성능이 제대로 나오는지 확인하는 데 써요. 노트북은 전원을 꽂고 '최고 성능' 모드로 재세요.
인터넷 지연·속도 (브라우저 측정)

여러 서버에 짧은 요청을 20번씩 보내 응답 시간(지연), 흔들림(지터), 실패율, 다운로드 속도를 재요. 웹 요청 기준이라 게임 안의 핑보다 조금 높게 나오는 게 정상이에요.

대상지연(중간값)최소지터실패판정
게이트웨이 핑·외부 핑 (윈도우 점검 프로그램)

공유기/스위치(게이트웨이)까지, 통신사 DNS·구글·클라우드플레어까지 진짜 핑(ICMP)과 게임사 서버 접속 시간(TCP)을 재려면 pc-check.bat을 실행하고 결과를 내 사양 탭에 붙여넣으세요.

아직 붙여넣은 결과가 없어요.

읽는 법 · 게이트웨이 핑이 1~2ms를 넘거나 손실이 있으면 PC~공유기 구간(랜선·랜카드·허브) 문제예요. 게이트웨이는 정상인데 외부만 높으면 통신사 회선 문제예요. 모든 대상이 같이 흔들리면(지터 큼) 같은 매장 안에서 누가 대용량을 받고 있는지 확인하세요.
모니터 주사율

144Hz 모니터인데 60Hz로 잡혀 있는 경우가 PC방에서 가장 흔한 문제예요. 측정 중엔 마우스를 움직이지 마세요.
