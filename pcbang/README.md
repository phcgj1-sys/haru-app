# PC방 게임 점검 — 매장 설치·운영 안내

좌석마다 "인기 게임이 잘 돌아가는지"와 "장비·네트워크에 고장이 없는지"를 점검하고, 매장 전체 결과를 한 화면에서 모아 보는 도구예요. 웹 앱(`index.html`)과 윈도우 점검 프로그램(`pc-check.bat` + `pc-check.ps1`) 두 부분으로 되어 있어요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html`, `app.js`, `data.js` | 웹 앱. 게임 판정, 브라우저 벤치마크, 인터넷 지연, 장비 테스트·체크리스트, 문제 해결 안내, 매장 현황 |
| `pc-check.bat` | 더블클릭용 실행 파일. 옆의 `pc-check.ps1`을 실행해요 |
| `pc-check.ps1` | 윈도우 점검 프로그램. 부품·드라이버·보안 부팅·TPM·모니터 최대 주사율·게이트웨이/외부 핑 등을 읽어 결과 코드(`PCBANG1:`)를 만들어요 |
| `pc-check.config` (직접 만듦) | `share=\\SERVER\pcbang` 한 줄. 결과를 모을 공유 폴더 |

## 처음 설치 (권장 순서)

1. **공유 폴더 만들기:** 카운터 PC나 매장 서버에 폴더를 만들고(예: `D:\pcbang`), 공유 이름 `pcbang`으로 공유해요. 좌석 PC 계정이 **쓰기**를 할 수 있어야 해요.
2. **점검 프로그램 놓기:** `pc-check.bat`, `pc-check.ps1`, `pc-check.config`를 한 폴더에 둬요.
   - 노하드(디스크리스) 매장은 서버 이미지의 바탕화면이나 `C:\pcbang`에 넣고 이미지를 저장해요.
   - `pc-check.config`의 내용 예시: `share=\\SERVER\pcbang`
3. **좌석 번호:** PC 이름이 `PC-023`, `SEAT23`, `A-023`처럼 끝에 번호가 있으면 자동으로 23번 좌석이 돼요. 이름이 다르면 `pc-check.bat -Seat 23`처럼 실행해요.
4. **점검:** 좌석에서 `pc-check.bat`을 더블클릭해요(약 45초, 관리자 권한 필요 없음). 결과가 공유 폴더에 `seat-23.txt`로 저장되고 클립보드에도 복사돼요.
5. **웹 앱으로 장비 확인:** 같은 좌석에서 웹 앱을 열어 **점검 시작 → 전체 자동 점검**, 이어서 **장비 테스트**의 체크리스트(화면 색 검사, 헤드셋 좌우, 마우스, 필수 키)를 채워요. **결과 파일 저장**으로 받은 `seat-23.txt`도 공유 폴더에 넣어요.
   - 좌석 바로가기 주소 끝에 `?seat=23`을 붙이면 좌석 번호가 자동으로 들어가요.
6. **매장 현황:** 카운터 PC에서 웹 앱 → **매장 현황** → 공유 폴더의 `seat-*.txt`를 모두 끌어다 놓아요. 바로 고칠 좌석, 조치 방법, 같은 사양 대비 성능이 떨어진 좌석이 정리돼요. **보고서 인쇄**로 점검표를 뽑고, **백업 받기**로 기록을 보관해요.

## 점검 주기 추천

- **매일 오픈 전:** 문제가 신고된 좌석만 장비 체크리스트.
- **매주:** 모든 좌석 `pc-check.bat` 실행 → 매장 현황에서 새로 생긴 문제와 "지난 점검과 달라진 점" 확인.
- **이미지·드라이버·윈도우 업데이트 직후:** 좌석 몇 개만 점검해서 주사율·전원 옵션·보안 부팅이 바뀌지 않았는지 확인.

## 실행이 막힐 때

- **"Windows의 PC 보호" 창:** `추가 정보 → 실행`을 눌러요. 파일 속성에서 `차단 해제`를 체크해도 돼요.
- **PowerShell 실행이 정책으로 막힘:** 그룹 정책이나 PC방 관리 프로그램이 스크립트를 막은 경우예요. 관리 업체에 `pc-check.ps1` 실행 허용을 요청해요(서명된 버전을 받을 수 있으면 그게 가장 안전해요).
- **공유 폴더에 저장 안 됨:** 좌석 계정의 쓰기 권한과 경로(`\\SERVER\pcbang`)를 확인해요. 저장에 실패해도 결과는 클립보드와 바탕화면 `pc-check-result.txt`에 남아요.
- **zip 안에서 바로 실행:** zip을 먼저 모두 풀어야 해요.

## 수집하는 정보와 보안

- 점검 프로그램은 이 PC의 부품·설정·네트워크 측정값만 읽어요. 사용자 파일, 계정, 비밀번호, 개인정보는 읽지 않아요. 결과는 클립보드, 바탕화면 파일, 지정한 공유 폴더에만 저장하고 인터넷 어디로도 보내지 않아요.
- 네트워크로 나가는 것은 핑(게이트웨이, KT·SK·LG U+ DNS, 구글, 클라우드플레어)과 게임사 웹 서버 접속 시간 측정(TCP 443)뿐이에요.
- 웹 앱도 결과를 브라우저 저장소에만 둬요. 인터넷 측정 때만 클라우드플레어·구글·네이버·넥슨·라이엇 서버에 짧은 요청을 보내요.

## 알아 둘 한계

- 예상 FPS는 부품 성능 점수와 공개 측정값으로 계산한 추정치예요(±30%). 롤·발로란트·오버워치 2·배그는 공개 측정값으로 보정했고, 나머지 게임은 사양 비례 추정이에요.
- 브라우저는 CPU 모델명·정확한 RAM·핑(ICMP)을 읽을 수 없어요. 정확한 판정은 점검 프로그램 결과를 함께 써야 해요.
- 램 XMP 꺼짐 판정은 일부 제조사 메모리에서만 정확하고, 노하드 감지는 추정이에요.
- 게임 요구 사양과 오류 코드 안내는 2026년 11월 기준이에요. 게임 업데이트로 바뀔 수 있어요(`data.js`의 `GAMES`, `FIXES`에서 고쳐요).
